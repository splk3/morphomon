# Morphomon Sandboxes

This directory contains self-contained scenes for testing and prototyping specific game mechanics, as mandated by `GEMINI.md`.

## Available Sandboxes

### 1. Mechanics Test (`mechanics_test.tscn`)
- **Purpose:** Testing basic player movement, jumping, and physics feel.
- **Key Features:** Infinite floor (WorldBoundary), basic camera following, and "Mechanics Sandbox" label.
- **Assigned To:** Kaylee (Game Dev)

## How to use
To run a sandbox:
1. Open the `.tscn` file in the Godot Editor.
2. Press **F6** (Run Current Scene) to launch just the sandbox.
